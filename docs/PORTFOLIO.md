# 作品集讲述提纲

## 一句话

对照是面向 AI 产品经理的文档生成方案评测台，以场景任务与评分锚点组织人工盲评，输出可追溯的方案对比报告。

## 展示顺序（约三分钟）

1. 问题：选模型或 Prompt 版本时，为什么“这份看起来更好”不足以支持决策？
2. 决策：为什么首版选择同任务对照、独立评分、统一揭晓，而不是先堆模型数量？
3. 操作：读材料，对两份输出打分，并对事实错误补充原文依据。
4. 结果：展示报告中均分、事实低分、有效数据量及单题依据，解释为什么高总分不必然等于可上线。
5. 边界：示例是人工编写；真实调用和真实用户验证尚未完成。
6. 下一步：用实际文档任务收集试用反馈，再决定是否引入 AI 初评。

## 可以展示的实际产物

一份 PRD、一套三维度评分标准、一个可运行产品、四个演示任务、评分与报告导出、自动化规则及接口测试。

这些是当前项目的产出数量，不等于真实用户数量、真实模型测试样本或商业效果。

## 简历建议（完成真实试用后再补结果）

设计并通过 AI Coding 实现文档生成方案评测台，定义事实忠实度、要求完整度与结构可用性评分标准，完成任务导入、匿名对照评分、问题记录及报告导出；通过服务端随机映射、标准快照和缺失数据处理，支持文档生成方案的可追溯评估。

不要写“提升选型效率 X%”“已服务多家企业”“独立研发底层算法”等尚无证据支持的内容。应能解释产品取舍、数据流和关键验收，并说明代码由 AI 辅助完成。
